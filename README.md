# Dien Hong Smart Nursing Home

An system for **Dien Hong Nursing Home**. It uses a radar and AI alerts to watch over residents, tells nurses fast when something abnormal happens, and keeps residents' families informed.

**Main goal: reduce the overload of Care Staff.**

Course project for DBIZ2, VJCBI College - FTU.

## Who uses it

- **Receptionist**: creates and updates resident profiles.
- **Nurse (Care Staff)**: views profiles and condition history, updates a resident's condition, receives alerts, chats with families.
- **Residents' Family**: receives notices about their resident, views the resident's condition, chats with nurses.
- **BOD** (board): views reports.
- **Admin**: sets up accounts and roles, monitors the radar, views access and action logs.
- **Radar** (external system): detects abnormal events and sends them to the app.
